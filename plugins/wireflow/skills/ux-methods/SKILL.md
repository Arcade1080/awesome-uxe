# UX-Methoden für Wireflow Studio

Leitsätze:

1. **Das Warum zuerst.** Jeder Schritt eines Flows beruht auf Wissen über Nutzer:innen oder ist als Annahme markiert. Menschen entscheiden, was belegt ist.
2. **Das Design System ist das Material.** Screens bestehen aus echten Komponenten; was fehlt, ist eine dokumentierte Lücke, kein Eigenbau.
3. **Ein Modell, mehrere Sichten.** Journey, Flow, Screens und Prototyp sind Sichten auf dieselben Dateien unter `.wireflow/`.
4. **Ehrliche Unsicherheit.** Offene Fragen und riskante Annahmen sind sichtbar und bekommen Tests.
